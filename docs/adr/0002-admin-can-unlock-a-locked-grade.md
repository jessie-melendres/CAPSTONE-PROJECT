# A locked grade can be reopened, but only by an administrator

`GradeService::unlock()` already existed with a docblock describing it as an "Administrator override to reopen a locked grade for correction," but no route or controller action anywhere actually called it — the only lock-related route belonged to the same faculty member who could lock it, making a locked grade permanently frozen in practice despite the roadmap naming this an "Immutable Historical Records System." We wired `unlock()` up as an admin-only route (`AdminController::gradeUnlock`) rather than deleting it or exposing it to faculty, so that a locked grade is immutable *to the faculty member who locked it* (preventing after-the-fact tampering by the grade's author) while still being correctable by an administrator when a legitimate correction is needed — matching the "override," not "faculty self-service," framing already implied by the existing code comment.
